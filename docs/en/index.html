01 · WHY MISAKI

Learning should not reset with every chat.

The phrases you asked about, nuances you explored, and mistakes you actually made are useful learning context. Misaki keeps original conversations, evolving study material, and evidence from real answers separate, so ChatGPT can retrieve and build on them later.

02 · ARCHITECTURE

Simple, inspectable, reproducible.

ChatGPT handles tutoring and judgment. Site MCP implements data operations and transactions. D1 stores records persistently. No extra model is hosted on the backend.

Want to learn a different language?

Misaki is primarily designed for learning Japanese with Traditional Chinese explanations. If you want a different, fixed learning direction, use the adaptation prompt to guide your own ChatGPT/agent in updating a separate copy of the instructions and tool descriptions, then test the result. Other language pairs are not officially maintained or validated by this project.

Project status and limitations

The repository includes source code, 13 MCP tools, database migrations, tests, and reconstruction instructions. The original private Sites + D1 service has undergone read/write checks; this reorganized repository and installation in a different account still need independent end-to-end validation. Actual deployment depends on Sites and Plugin features available in each ChatGPT account. Making this GitHub repository public does not make a private Site public.
