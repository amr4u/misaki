01 · WHY MISAKI

學習不該每次對話都從零開始。

查過的日文、問過的語氣差異、實際練習時犯的錯，都是值得保留的學習脈絡。Misaki 分開保存原始問答、可整理的教材與真正的作答證據，讓 ChatGPT 能在後續對話中查詢、整理與選題。

02 · ARCHITECTURE

簡單、清楚、可自行重建。

ChatGPT 負責日文教學與判斷，Site MCP 負責可靠的資料操作，D1 負責持久保存；不在後端另外託管模型。

03 / MISAKI

目前狀態與限制

Repo 已包含原始碼、13 個 MCP 工具、資料庫 migration、測試與重建步驟。原始私人服務曾完成 Sites + D1 讀寫驗證，但此 repo 的整理版本與跨帳戶重建仍需獨立驗收。實際可用功能取決於各 ChatGPT 帳戶的 Sites／Plugin 權限。請不要將 GitHub 原始碼公開與實際私人 Site 的存取設定混為一談。
