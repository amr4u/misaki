# 需求與範圍

本文件保存通用需求摘要。個人問答、完整需求原文與私人決策脈絡，保存在各自 D1 的 project_context，不隨 repo 分發。

## 優先順序

1. 維護並繼續開發我們自己的 Misaki；這個 repo 是後續開發依據。
2. 讓其他使用者的 ChatGPT 讀取 repo 後，理解如何在自己的帳戶重建。

維持簡單。以完整程式、文件及 prompts/ 達成第二項，不另建安裝器、自動升級平台或完整知識圖譜。

## 架構與學習需求

- 核心為 Plugin → Site MCP → D1；ChatGPT 分析、Site 執行資料操作、D1 持久化。
- Misaki 自動保存日文翻譯、改錯、詞彙與文法問答；成功回應才算保存。
- Raw 不因整理改寫；Metadata 可放標籤與註記，processed 要容易判斷。
- 跨問答整合共同主題；舊 Raw 可再次比較，來源保留多對多關聯。
- 目標是改善日文理解、記憶與實際運用；教材配合回想、造句、情境及改錯。
- 學習進度以實際作答為證據，不把問過、整理過或一次答對等同掌握。
- 需求、參考資料、最後決策及理由要能查詢，改變決定時保留舊版本。
- 使用自然台灣繁體中文，日文附整句假名。個人程度依使用者提供資訊調整。
